AliProbe

Ficha, precio y conformidad del fabricante de cualquier producto AliExpress

Abrir la app en vivo

Sobre el proyecto

  • Next.js 15 + Tailwind CSS
  • Puppeteer con Chromium: captura la API interna mtop.aliexpress.pdp.pc.query
  • Extrae titulo, precio, imagenes, vendedor, atributos y conformidad del fabricante
  • Base de datos SQLite local (data/app.db) o Supabase en remoto
  • Desplegable con Dockerfile en cualquier hosting (Railway, Render, Fly.io)
